# ESP8266 GPS Solar Tracker "HelioCore AI"

Цей проєкт є сонячним трекером на базі плати NodeMCU v2 (ESP8266). Він використовує GPS-модуль для визначення координат та часу, компас для орієнтації та драйвер двигуна для повороту сонячної панелі в напрямку сонця.

Керування та моніторинг здійснюються через вбудований веб-сервер, а основна інформація відображається на OLED-дисплеї.

## Основні можливості

*   **Три режими роботи:** Тестовий, Резервний (рух за фіксованим кутом) та Робочий (відстеження сонця за GPS).
*   **Веб-інтерфейс:** для налаштування Wi-Fi, вибору режиму роботи та калібрування.
*   **OLED-дисплей:** для відображення статусу системи, координат, часу та іншої інформації.
*   **Керування DC-двигуном:** для повороту конструкції за азимутом.
*   **Підтримка OTA:** для оновлення прошивки "по повітрю".
